# 酿见 AI · 评委快速体验

> 目标：评委不安装 Python、Node.js，也不需要配置 API Key，打开一个公开链接即可完成核心体验。

## 推荐体验方式：公开 Demo 链接

比赛提交时，优先提供一个可直接访问的在线地址。

进入页面后：

1. 点击首页 **「30 秒一键体验演示」**；
2. 系统自动装配演示酒厂档案并运行完整营销链；
3. 在结果区依次查看：
   - **策略诊断**：优先消费者、生活场景、下一步建议；
   - **内容资产**：公众号、朋友圈、短视频；
   - **发布检查**：事实证据缺口与酒类营销风险；
4. 向下查看评论区承接建议。

无需注册、无需登录、无需填写表单即可看到完整结果。

## 在线部署：Render（单服务）

仓库根目录已经提供：

- `Dockerfile`：一次构建 React 前端 + FastAPI 后端；
- `render.yaml`：Render Blueprint 配置；
- `/api/health`：部署健康检查地址。

### 部署步骤

1. 登录 Render；
2. 新建 Blueprint；
3. 选择本 GitHub 仓库；
4. Render 会自动读取根目录的 `render.yaml`；
5. 确认后部署；
6. 部署完成后会获得一个 `*.onrender.com` 的公开地址；
7. 把这个地址填入比赛提交材料、README 和演示说明。

当前规则版 Demo 不依赖外部大模型 API Key，因此公开演示不需要额外密钥。

> 如果使用 Render 免费实例，长时间无人访问后首次打开可能需要等待服务唤醒。正式评审前建议提前访问一次确认服务在线；如需更稳定的现场体验，可以在评审期间临时使用非休眠实例。

## 备用方式 A：Docker 本地运行

评委或技术人员如果希望本地复现：

```bash
git clone https://github.com/jryyu91-cmd/jiuzhen-agent.git
cd jiuzhen-agent
git checkout feature/marketing-agent-v2
docker compose up --build
```

浏览器打开：

```text
http://localhost:5173
```

## 备用方式 B：Mac / Linux 一键启动

```bash
git clone https://github.com/jryyu91-cmd/jiuzhen-agent.git
cd jiuzhen-agent
git checkout feature/marketing-agent-v2
zsh setup.sh
```

浏览器打开：

```text
http://localhost:5173
```

需要本机已有：

- Python 3.10+
- Node.js 18+

## 比赛提交建议

最终提交材料建议同时保留四个入口：

1. **公开体验地址**：评委首选，点开就能测试；
2. **GitHub 仓库地址**：查看代码与技术实现；
3. **60-90 秒演示视频**：防止评审网络环境不稳定；
4. **本地运行说明**：作为技术复现备用。

## 提交前自检

- 使用无痕窗口打开公开 Demo，确认无需登录；
- 点击「30 秒一键体验演示」，确认能完整生成；
- 依次测试策略诊断 / 内容资产 / 发布检查；
- 测试公众号、朋友圈、短视频 Tab 和复制按钮；
- 打开 `/api/health`，确认返回 `status: ok`；
- 手机浏览器至少测试一次响应式布局；
- 正式提交前重新播放一遍演示视频，确保视频内容与当前版本一致。
