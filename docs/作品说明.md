# 作品说明 · 酒阵 Agent

> 多彩贵州·贵客松 | 赛道二 · 传统行业 AI 解决方案 | AI × 白酒

## 1. 作品名 + 一句话

**酒阵 Agent** —— 把酱酒厂市场部一个人的内容产能，放大成一个团队。（25 字内）

## 2. 谁在用

遵义县级酱酒厂市场部的那一个人（往往还兼任销售）。他每周要交 3 篇公众号、5 条朋友圈、2 条短视频脚本，一个人对着空白文档发呆一上午。

## 3. 没有它的时候怎么办

现在的动作：百度搜同行文案 → 抄改 → 不敢发产区细节（怕写错被懂行的笑话）→ 短视频脚本直接不做。

具体的损耗：内容产出周期 2-3 天/篇；渠道断了互动（评论没人回，客户流失）；请代运营报价 3000-8000 元/月，县级酒厂预算养不起。

## 4. 你做了什么（只写一条主路径）

输入酒厂名称、产品、价格带、卖点、品牌语气 → 一键生成「公众号文案 + 朋友圈短文案 + 短视频脚本」三件套 → 自动附评论区高频问题回复建议（价格咨询/真假质疑/要链接/送礼场景四类）。

## 5. 演示怎么看

前端界面（左表单右结果）：http://localhost:5173

三步复现：
1. 打开页面，表单已预填「茅台镇老烧坊」示例
2. 点击「生成内容三件套」
3. 依次切换三个 Tab 看产出，展开「评论区互动建议」

API 直达（评委自测）：
```bash
curl -X POST http://localhost:8000/api/generate -H "Content-Type: application/json" \
  -d '{"name":"茅台镇老烧坊","product_name":"老烧坊·窖藏10","price_range":"388元","selling_points":["大曲坤沙"]}'
```

## 6. 用了什么

- 后端：Python FastAPI + Pydantic，流水线引擎 `backend/app/pipeline.py`
- 前端：React 18 + Vite + TypeScript
- 生成模式：48 小时版本为模板+规则引擎（离线可跑、演示稳定）；`USE_LLM=1` 时切换 LLM 生成（接自有知识榨干引擎，见第 8 栏）
- 数据来源：全部为演示用虚构酒厂信息 + 公开产区常识，无企业机密

## 7. 哪些是这 48 小时做的（声明基线）

48 小时内全新完成：后端流水线、前端界面、评论区规则引擎、部署说明。
已有资产复用声明：团队此前自研的「知识榨干引擎」（内容生产 Python 流水线，非比赛期间开发）作为 LLM 模式的架构参考与后续接入对象；比赛版本未使用其代码。

## 8. 再给 100 天，先做什么

第一步：回遵义找 1 家酱酒厂免费试用，把它的真实产品资料灌进来，验证「输入 10 分钟、产出三件套」能不能跑通，再谈付费。
