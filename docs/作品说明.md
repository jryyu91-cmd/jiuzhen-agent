# 作品说明 · 酒阵 Agent

> 多彩贵州·贵客松 | 赛道二 · 传统行业 AI 解决方案 | AI × 白酒

## 0. 为什么是这个题目（产业痛点）

不是「AI 能写文案所以做个写文案工具」，而是行业真实处境（2026 年公开报道交叉印证）：

- **超八成中小酒企利润率走低**，行业集中度持续提升，2023-2025 年年均并购超 20 起、八成以上是头部并购地方中小酒企——中小酒企正被加速出清（腾讯新闻 2026-08、南都湾财社）。
- **头部用重资产营销碾压**：古井贡签古天乐、水井坊签梁朝伟，明星代言+全域投放锁死用户心智；区域酒企「盲目跟风只会投入高、转化低、无沉淀」。
- **「三缺」现状**（酒业分析师肖竹青）：缺品牌高度、缺资金、缺人才——精细化运营、直播电商玩法跟不上，「价格卖不上去、费用降不下来、库存天天涨」。
- **内容能力几乎空白**：多数地产酒品牌传播停留在户外广告+本地电视台+宴席促销，「对内容营销、用户运营、场景化传播几乎没有布局」（今日头条·地产白酒生存危机分析）；品牌与年轻人脱节，「长辈喝的酒」心智固化。
- **代运营养不起**：市场上白酒行业代运营基础套餐 3000-8000 元/月，进阶 1.5-3 万/月（搜狐·新媒体代运营收费调研），县级酒厂市场部往往只有 1 个人，预算和人都撑不起。

**结论**：中小酒企的内容宣传困境不是「不会写」，是「没人、没钱、没方法」三件事同时发生。酒阵 Agent 针对的就是这个结构性缺口。

## 1. 作品名 + 一句话

**酒阵 Agent** —— 把酱酒厂市场部一个人的内容产能，放大成一个团队。（25 字内）

## 2. 谁在用

遵义县级酱酒厂市场部的那一个人（往往还兼任销售）。他每周要交 3 篇公众号、5 条朋友圈、2 条短视频脚本，一个人对着空白文档发呆一上午。

## 3. 没有它的时候怎么办

现在的动作：百度搜同行文案 → 抄改 → 不敢发产区细节（怕写错被懂行的笑话）→ 短视频脚本直接不做。

具体的损耗：内容产出周期 2-3 天/篇；渠道断了互动（评论没人回，客户流失）；请代运营报价 3000-8000 元/月起步，县级酒厂预算养不起。

## 4. 你做了什么（只写一条主路径）

**一厂一档 → 一键三件套 → 评论区兜底**：

1. **建档**：每家酒厂一份品牌档案（语气红线、选题倾向、场景素材库——如「酒师傅凌晨四点看酒醅」）。
2. **生成**：按档案装配上下文，一条主链路产出「公众号文案 + 朋友圈短文案 + 短视频脚本」，收尾遵循共创方法论（收成一句记得住的话 + 给一个具体行动，禁总结腔）。
3. **兜底**：自动生成评论区高频问题回复建议（价格咨询/真假质疑/要链接/送礼场景四类）。

个性化定制机制：档案即提示词工程——同一价位的两家酒厂（演示档案「老烧坊」388 元匠人叙事 vs「青溪小坛」168 元朋友聊天体），生成内容风格完全不同。该机制参考了成熟的多客户矩阵运营实践（一客一档一上下文），正式版档案可存飞书多维表格，由酒厂自己维护。

## 5. 演示怎么看

前端界面：http://localhost:5173

三步复现：
1. 打开页面，顶部「一厂一档」栏点任意酒厂按钮（或左侧表单自定义填写）
2. 点击生成，依次切换公众号 / 朋友圈 / 短视频脚本三个 Tab
3. 展开「流水线轨迹」看装配过程，查看「评论区互动建议」

API 直达（评委自测）：
```bash
# 档案列表
curl http://localhost:8000/api/profiles
# 按档案生成
curl -X POST http://localhost:8000/api/generate/by-profile/qingxi
```

## 6. 用了什么

- 后端：Python FastAPI + Pydantic，流水线引擎 `backend/app/pipeline.py`
- 前端：React 18 + Vite + TypeScript
- 写作方法论：粥左罗人×AI 内容共创体系（场景开头/段间递钩子/收尾三选一/去AI味三参数），模板版已内化该纪律；LLM 版直接以方法论作 system prompt
- 生成模式：48 小时版本为模板+规则引擎（离线可跑、演示稳定）；`USE_LLM=1` 时切换 LLM 生成
- 数据来源：演示档案为虚构酒厂；产业痛点数据来自 2026 年公开报道（腾讯新闻/雪球/南都湾财社/今日头条），见第 0 栏

## 8. 再给 100 天，先做什么

第一步：回遵义找 1 家酱酒厂免费试用，花一周替它建品牌档案（访谈市场部那个人 + 收集酒厂真实场景细节），验证「建档一天、之后每周 10 分钟出三件套」能不能跑通，再谈按厂年费订阅。
